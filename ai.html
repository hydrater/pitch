Multi-Agent System

Specialized Agents

Each stage of the pipeline is handled by a purpose-built AI agent with specific instructions and access to prior results

Strategy Agent

Receives an archetype (e.g. "mean reversion using RSI") and writes a complete optimizer from scratch. Self-reviews against 20 documented bias patterns before execution. Runs up to 3 rounds — each round narrows parameter ranges around the best results from the previous.

Research Agent

Activated when built-in archetypes are exhausted. Reads every passed strategy, every failure post-mortem, and the aggregated failure statistics. Generates 10 novel strategy ideas that specifically avoid known failure patterns and target gaps in the current portfolio.

Post-Mortem Agent

Analyzes each failed strategy in depth — was the signal logic flawed? Were parameter ranges too narrow? Did the exit rules cause problems? Writes a root cause analysis that feeds directly into the research agent's next round of ideas.

Alignment Agent

Verifies that the live trading engine produces identical results to the optimizer. If there's a mismatch (common due to execution timing), a specialized debugging agent traces and fixes the discrepancy.
